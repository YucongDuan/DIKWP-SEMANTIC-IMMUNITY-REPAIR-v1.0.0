# Contributing

Contributions are welcome for additional languages, audited pattern packs, accessibility improvements, user-controlled friction designs and evaluation datasets.

Every pull request should state:

1. the semantic risk mechanism addressed;
2. which protected-expression false positive could be introduced;
3. the added tests;
4. whether any external network, storage or high-impact action is introduced;
5. how an affected creator can understand and appeal the result.

Do not submit person-level moral scoring, political-conformity scoring, hidden blacklists or automatic external punishment features.
