          L4–L5
          变现暂停与法定处置

          高风险商业主张可暂停变现并复核；违法或迫近伤害只由具名有权主体限时处置，并保留申诉。

          不可跨越的宪法

          • 负面情绪、悲观、批评、揭弊和不利证据不是“负信息”。
          • 系统不建立人的善恶分、正能量分、认知等级或秘密黑名单。
          • 不能可靠推断主观恶意；“故意欺骗”必须有独立证据。
          • 去放大、暂停变现或移除必须附理由、期限、通知、申诉和纠错。
          • 平台不得从惩罚、保证金或修复金中获得不透明利润。
          • 算法只形成建议；现实高影响决定由具名主体承担。

          现实部署四层

          1. Creator Linter：发布前发现绝对化、证据缺口和付费操纵。
          2. Reader Shield：本地显示语境卡、反例与分享摩擦。
          3. Platform Gate：透明去放大、变现保证金、人工复核与公开理由码。
          4. Community Repair：现实关系中把口号改造成共同责任、资源安排和复盘指标。

          研究型参考实现：不执行事实核查、医疗/法律诊断或自动内容删除。它把“主动消除”定义为主动消除欺骗与操纵对人的控制力，同时保护真实的坏消息、异议和痛苦表达。
