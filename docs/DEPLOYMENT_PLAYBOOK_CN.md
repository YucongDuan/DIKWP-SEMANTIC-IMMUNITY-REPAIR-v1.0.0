# SIRR 部署手册

## A. 个人与家庭

- 使用离线HTML分析一段话；
- 只保存本人主动导出的文件；
- 用关系修复卡制定七日安排；
- 不用分析结果给伴侣或家人贴“操纵者”标签。

## B. 学校与社区

- 先用于媒体素养和案例讨论；
- 使用合成案例，避免公开未成年人记录；
- 评价能否识别边界、反例、来源和利益关系；
- 禁止把系统得分用于纪律处分或学生排名。

## C. 内容平台

建议四个API边界：

```text
POST /semantic-analysis
POST /context-card
POST /intervention-proposal
POST /appeal-and-correction
```

平台应记录：模型版本、规则版本、输入摘要、理由码、人工复核者、期限和申诉结果。平台不得将风险分直接转化为秘密降权。

## D. 知识付费与广告

高风险领域商业内容应披露：

- 具体主张；
- 证据等级；
- 适用和不适用对象；
- 利益冲突；
- 退款；
- 可能的不良结果；
- 现实效果评估方式。

## E. 90日试点

### 0—30日

- 选择一个场景：育儿内容、健康营销、金融短视频或教育课程；
- 标注至少300条合成或合法获取的样本；
- 建立独立批评者和受影响群体参与的治理组；
- 确定误伤红线。

### 31—60日

- 只上线语境卡和分享摩擦；
- 不进行自动移除；
- 测量分享、理解、申诉和误伤；
- 对不同文化和语言做差异测试。

### 61—90日

- 对高风险商业内容试点透明变现暂停和人工复核；
- 发布理由码分布、申诉成功率和纠错时间；
- 证明真实批评和揭弊没有被系统性误伤后，再考虑扩大。

## F. 停止条件

出现以下任一项应暂停部署：

- 负面语气显著提高受限概率；
- 某性别、阶层、地区或语言出现无法解释的误伤；
- 申诉渠道无法实际恢复传播或变现；
- 平台以系统为借口压制批评；
- 风险分被用于就业、信用、保险或社会信用；
- 人工复核成为形式签字；
- 隐藏名单跨Agent或跨产品传播。
