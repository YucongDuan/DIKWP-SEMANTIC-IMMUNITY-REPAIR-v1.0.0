# DIKWP SIRR 快速开始

## 直接使用

双击：

```text
DIKWP_SEMANTIC_IMMUNITY_REPAIR_OS_v1.0.0.html
```

选择预设或粘贴一段帖子、课程话术、短视频文案或现实对话，调整领域、证据、来源、传播和商业参数，点击“主动分析并生成修复方案”。

## 安装浏览器护盾

1. 打开 Chrome/Edge 扩展管理页；
2. 开启开发者模式；
3. 解压 `DIKWP_SEMANTIC_IMMUNITY_BROWSER_EXTENSION_v1.0.0.zip`；
4. 选择“加载已解压的扩展程序”；
5. 在网页中选中文本并右键分析。

## Python

```bash
python DIKWP_SEMANTIC_IMMUNITY_REPAIR_OS_v1.0.0.pyz demo --output .sirr-demo
python DIKWP_SEMANTIC_IMMUNITY_REPAIR_OS_v1.0.0.pyz analyze case.json --output .sirr-case
python DIKWP_SEMANTIC_IMMUNITY_REPAIR_OS_v1.0.0.pyz serve --host 127.0.0.1 --port 8765
```

## 最重要边界

- 负面情绪、批评、揭弊和坏消息不因负面而受限；
- 系统不判断人是好人、坏人或“低认知”；
- 故意欺骗需要独立证据；
- 去放大、暂停变现和移除是人工治理提案；
- 自动外部行动权限为零。
